# ESP32
Different types of codes for using esp32 (captive-portal, network-sniffer, IDS)

To setup your Captive Portal using micropython:
1. Save index.html and new_update_main.py/main.py using Thonny IDE.
2. Edit the python file for Tweaking configurations.

To setup your captive portal natively in esp32 using C++:
1. Save the file inside the CPP folder with name RougeAP using Arduino IDE and upload the code.
2. Edit the file for Tweaking configurations.
